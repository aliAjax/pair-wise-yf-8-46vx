# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移并生成试映前破损提醒。

## 修复工单

- 划痕、齿孔、接片等破损片段自动生成修复工单，可登记负责人、预计完成时间与处理结果（未完成 / 修复中 / 已修复待复检 / 复检通过）。
- 复检通过前片段不进入可放映顺序；可临时启用备用片段顶替放映，原片段的修复进度仍然保留。
- 处理结果回退、时长变化或再次标为破损时，旧的复检通过记录会失效并留档（工单卡片与导出清单中均可查看）。
- 顶部统计待修数量与超期风险，试映前核对面板按超期、待修、已通过、颜色偏移分组提醒，导出清单同步包含工单与留档记录。
- 数据保存在浏览器 localStorage，重开页面可继续处理。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
