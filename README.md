# 胶片分镜条核对台

一个纯前端本地应用，用来整理纸质放映胶片片段、拖拽调整放映顺序、统计总时长、筛选颜色偏移，并为受潮胶片登记**修复工单**、跟踪复检。

直接打开 `index.html` 即可使用（数据保存在浏览器 localStorage，重开页面可继续处理），也可以在本目录启动静态服务访问。

## 修复工单流程

- 划痕（轻微划痕）、齿孔（齿孔破损）、接片（接片松动）三类问题片段会进入下方「修复工单」面板，可登记**负责人**、**预计完成时间**和**处理结果**（未完成 / 待复检 / 通过）。
- **复检闸口**：没有有效的「复检通过」记录前，片段不会进入中间的「可放映顺序」，也不能被排进试映。
- **备用片段**：待修片段可一键「启用备用片段」。备用片以完好状态顶替进入放映顺序，原片段仍保留全部工单进度和复检留档。
- **通过记录失效与留档**：以下情况旧的通过记录自动失效但保留在卡片和导出中可查——
  - 处理结果从「通过」改回「未完成」或「待复检」；
  - 通过后片段时长发生变化；
  - 通过后破损情况被再次改标。
- **统计联动**：顶部展示可放映总时长、可放映片段数、待修数量、超期风险（预计完成时间已超期，或 24 小时内到期）；右侧核对栏按待修 / 需跳过 / 颜色偏移分组提醒。
- **导出清单**：按「可放映顺序 / 待修片段 / 需跳过」分段导出，包含负责人、预计完成时间、处理结果、复检通过时间与失效留档。
